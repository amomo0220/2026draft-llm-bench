# 2026 ドラフト × AI ライブ予測ベンチマーク

2026年プロ野球ドラフト会議（**2026-10-22**）の指名を、3社の AI に **ドラフトの1週間前に予想させ、その予想を公開して固定（事前登録）** したリポジトリです。ドラフトの後に、同じリポジトリのスクリプトで自動採点します。

知りたいのは「どの AI が賢いか」ではありません。**AI に何を渡すと（名簿だけ／Web 検索／調べて裏取りまで）予想がどう変わるか、どこで存在しない選手や誤った情報を書くか（ハルシネーション）** です。

## 事前登録

- 予想は `predictions/` にあり、タグ **`prereg-2026-10-15`** の時点で固定しています
- タグを打った後に `predictions/` を変えると、CI（`.github/workflows/prereg-guard.yml`）が失敗します。タグの移動・削除は GitHub のルールセットで禁止しています
- タグの後に作った予想は、`predictions/late/` に分けて置きます（採点では別の扱いにします）

## 予想させたこと

1. 12球団それぞれの **1位入札**（候補と確率）
2. 1位入札で **競合する選手** と球団数
3. **千葉ロッテマリーンズの1〜5位指名**

出力は JSON で受け取り、[スキーマ](src/schema.py)で検証しています。自由文の予想は採点しません。

## 実験の条件

どの条件でも、AI は自分が学習した知識（知識のカットオフまで）を使います。条件ごとに、そこへ何を足すかを変えています。

| 条件 | AI に渡したもの | 見たいこと |
| --- | --- | --- |
| B 記憶＋名簿 | 候補者マスタ（プロ志望届の提出者など）の氏名・所属・ポジション。AI は学習した知識（カットオフまで）と名簿で予想する | 最新情報なしでの判断（比較の出発点） |
| C Web 検索 | 各社の API の Web 検索（名簿は渡さない）。調べてメモを書く → JSON に整形 の2段階 | 最新情報を集める力 |
| D エージェント | Web 検索＋名簿を引くツール（draft-db）。調べる → 整形 → 名簿で自己検証 の3段階 | 自分で集めて確かめる効果 |

- モデル: `claude-sonnet-5-5`（Anthropic）、`gpt-5.6-terra`（OpenAI）、`gemini-3.8-flash`（Google）。各社の中位モデルで格をそろえています
- 各条件 × 各モデルを3回ずつ（計27回）実行し、ばらつきも見ます
- 実行ごとのモデル・条件・プロンプトのハッシュ・トークン数・コスト・時間・ツールの呼び出し回数は `runs/runs.jsonl` にあります

設計の詳細と決定の経緯は [docs/PLAN.md](docs/PLAN.md) にあります。

## 採点（ドラフト後）

1位入札の的中数、確率の当たり具合（ブライアースコア）、ポジションだけでも当たったか、ロッテ各順位の的中、名簿にない選手の名前（ハルシネーション）などを測ります（[src/scorer.py](src/scorer.py)、PLAN 3.6）。

## 構成

```
data/candidates.csv   候補者マスタ（高校・大学はプロ志望届の提出者全員。各行に出典 URL）
prompts/              条件ごとのプロンプト
predictions/          事前登録した予想（タグの後は不変）
runs/                 実行ログ
src/run.py            実行（条件 A〜D）
src/draft_db_mcp/     候補者マスタを引くツール（MCP サーバー）
src/scorer.py         採点
src/report.py         予想を表にまとめる
```

## 再現

```bash
uv sync
uv run pytest
cp .env.example .env   # API キーと BUDGET_USD を書く
uv run python -m src.run --condition D --model claude-sonnet-5-5 --n 1 --start 1 --dry-run   # 見積もりだけ
uv run python -m src.report          # 予想のまとめ
```

Web 検索の結果は日々変わるため、同じコマンドでも同じ予想にはなりません。事前登録した予想そのものが記録です。

## 注意

- 候補には高校生（未成年）が含まれます。このリポジトリは AI の予想の仕組みと精度を調べるためのもので、選手個人を評価するものではありません
- 新聞・Web 記事の本文や、取得した生データは含めていません（`data/raw/` は公開しません）。候補者マスタは公式の一覧をもとに自分で構造化したものです
- AI が書いた指名の理由（`reason`）や出典 URL は、AI の出力をそのまま記録したもので、内容の正しさは保証しません
