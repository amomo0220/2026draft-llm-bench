# AI 3社にドラフト1位を予想させて、答えが出る前に公開しました

**——10月22日の答え合わせまで、この予想はもう書き換えられません**

## この記事でやること

10月22日（木）は、2026年プロ野球ドラフト会議です。

その1週間前の今日、Claude（Anthropic）・ChatGPT の GPT（OpenAI）・Gemini（Google）の3つの AI に、次の3つを予想させました。

1. 12球団それぞれの **1位入札**
2. 1位で **競合する選手**
3. **千葉ロッテマリーンズの1〜5位**

そして、その予想を **答えが出る前に公開し、後から書き換えられない形で固定** しました。ドラフトが終わったら、この予想と実際の結果を突き合わせます。

きっかけは、ロッテのサブロー監督が、ドラフトや外国人選手の情報収集に AI（Claude Code）を使うと報じられたことです。「では、AI はドラフトをどこまで読めるのか」を、ごまかしの効かない形で試してみたくなりました。

## なぜ「事前登録」するのか

AI の予想記事でよくあるのが、結果が出た後に「AI はこう言っていた」と都合のよい回だけを紹介するパターンです。これでは、本当に当てたのかどうか分かりません。

そこで今回は、予想を **封筒に入れて封をし、第三者に預けるような仕組み** を作りました。

- 予想のファイルは GitHub（プログラムを公開・管理するサービス）に置き、公開した時点で「タグ」という目印を付けました
- 目印の後に予想のファイルが1文字でも変わると、自動チェックが失敗するようにしています
- 目印そのものも、動かしたり消したりできない設定にしています

うまく当たらなかった予想も、そのまま後編で公開します。

## AI に何をさせたか

### 3つの AI

| AI | 会社 |
| --- | --- |
| Claude Sonnet 5.5 | Anthropic |
| GPT-5.6 Terra | OpenAI |
| Gemini 3.8 Flash | Google |

各社の「真ん中のクラス」のモデルで、格と料金帯をそろえました。1社だけ最上位モデルを使うと、比べ方が不公平になるからです。

### 3つの条件：AI に何を渡すか

今回いちばん見たいのは「どの AI が賢いか」ではなく、**AI に何を渡すと予想が変わるか** です。そこで、同じ AI に3通りの条件で予想させました。スカウトにたとえると、次のようになります。

| 条件 | たとえると | AI に渡したもの |
| --- | --- | --- |
| B 名簿のみ | 候補者名簿だけ渡されたスカウト | プロ志望届の提出者などの名簿（氏名・所属・ポジション） |
| C Web 検索 | ネットで調べられる記者 | Web 検索。調べてメモを書き、そのメモから予想を出す |
| D エージェント | 調べて、名簿で裏を取るアナリスト | Web 検索＋名簿を引く道具。予想を出した後、全選手を名簿で確かめ直す |

名簿は、日本高等学校野球連盟と全日本大学野球連盟が公表したプロ志望届の提出者一覧をもとに作りました。高校生・大学生は志望届を出していないと指名できません。そのため、AI が志望届を出していない選手の名前を書いたら「指名できない選手を予想した」と判定できます。

各条件 × 各 AI を3回ずつ、計27回予想させました。同じ質問でも AI の答えは毎回少しずつ変わるので、1回だけでは「たまたま」と区別できないからです。

### 「AI」と「AI を動かす仕組み」は別物

サブロー監督の話題が出たとき、ネットでは「Claude Code は AI（モデル）ではなく、AI を動かす仕組み（ハーネス）だ」という反応がありました。

車にたとえると、AI のモデルはエンジン、ハーネスは車体と運転のしかたです。同じエンジンでも、地図（名簿）を積むか、カーナビ（Web 検索）を付けるかで、着く場所が変わります。今回の条件B〜D は、エンジン（AI）は同じまま、車体（渡すもの・手順）だけを変えた比較です。

### 準備中に見つけた「AI のうそ」

本番の前の試行で、印象的なことがありました。

Web 検索ができる条件で、最初は「調べてから JSON（決まった形式のデータ）で答えて」と1回で頼んでいました。すると Gemini は、4回試して4回とも **一度も検索しませんでした**。それなのに、ロッテの予想の「情報源」欄には URL を6件書いていました。検索していない以上、これらは AI が自分で書いた URL です。

そこで、「調べてメモを書く」と「メモから JSON に整形する」の2段階に分けました。すると3社とも検索するようになり、情報源の URL もすべて調査メモに実際に出てきたものになりました。**頼み方（手順）を変えただけで、AI の振る舞いが変わった** 例です。

## 答え合わせのしかた（後編予告）

ドラフト当日の結果が出たら、次の点を採点します。

- **1位入札の的中数**：12球団のうち、AI がいちばん確率が高いとした選手に実際に入札した球団の数
- **確信度の当たり具合**：「70%」と言った予想が、本当に7割くらい当たっているか（ブライアースコア）
- **ポジションの的中**：選手は外しても、「投手を取る」という読みは合っていたか
- **ロッテの1〜5位**：順位ごとの的中と、5人のうち何人が実際に指名されたか
- **ハルシネーション**：名簿にない選手、志望届を出していない選手の名前をどれだけ書いたか

条件ごと・AI ごとに比べて、「何を渡すと当たるようになるのか」を後編で報告します。
