## 自己検証

次の「予測（確認前）」は、調査メモをもとにあなたが作った予測です。提出する前に、draft-db のツール（search_players・get_player）で確認してください。

確認すること:
- first_round の候補、contested、lotte に出てくるすべての選手について、氏名・所属・ポジションを候補者マスタと照らし合わせる
- 高校生・大学生がマスタにいなければ、プロ野球志望届を提出しておらず指名できない。調査メモを参考に、指名できる選手に差し替える
- 氏名の表記、所属、ポジションの誤りを直す（マスタのポジションが空欄なら、調査メモに従う）
- 社会人・独立リーグ・二軍参加球団の選手は、マスタにいなくても誤りとは限らない
- 複数の選手を確かめるときは、1回の応答でまとめて（並列に）ツールを呼び出す
- 確認して直す必要がなければ、そのままでよい。確率の合計が 1.0 になること、ロッテが5人であることも確かめる

確認が終わったら、修正後の予測を、指定された JSON スキーマに従う JSON オブジェクト1つだけで出力してください。説明文は付けないでください。
